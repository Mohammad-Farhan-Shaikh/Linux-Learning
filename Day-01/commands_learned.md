# Day 01: Linux Basics

Today I started learning Linux on Ubuntu. I practiced basic navigation and file management.

## Commands Learned Today:
- `ls`: List files and folders in the current directory.
- `cd`: Change Directory (used to move between folders).
- `mkdir`: Make Directory (used to create a new folder).
- `pwd`: Print Working Directory (shows exactly where I am in the system).
- `nano`: A terminal-based text editor to write notes or code.
- `clear`: To clean up the terminal screen.
